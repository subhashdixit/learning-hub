# Learning roadmap — follow this order

[Home](../README.md)

**Start with Stage 01.** Read the foundations before progressing to data science, then AI engineering. Each stage contains its own numbered reading list.

**Python → Mathematics and Statistics → SQL and Data Analysis → Data Science → AI Engineering → RAG → Agents → Data Engineering → Production Operations → Interview Revision**

| Stage | Learning path | What to learn |
|---|---|---|
| **01** | [Python and Programming](python-and-programming.md) | Learn Python, environments, Git basics, and debugging. |
| **02** | [Mathematics, Statistics and Probability](mathematics-and-statistics.md) | Build the mathematical foundation for understanding data and models. |
| **03** | [SQL and Data Analysis](data-analysis.md) | Query, clean, explore, and visualize data. |
| **04** | [Data Science and Machine Learning](data-science.md) | Learn feature engineering, model training, validation, and interpretation. |
| **05** | [AI Engineering Foundations](ai-engineering.md) | Study LLMs, prompting, embeddings, retrieval, evaluation, and safety. |
| **06** | [RAG Development](rag-development.md) | Build on embeddings and retrieval to work with document-based applications. |
| **07** | [Agents, Tools and LangGraph](agent-development.md) | Study tool use, state, orchestration, human review, and agent evaluation. |
| **08** | [Data Engineering](data-engineering.md) | Study pipelines, PySpark, orchestration, and data quality; this can also follow Stage 3. |
| **09** | [MLOps and LLMOps](mlops-and-llmops.md) | Learn deployment, monitoring, versioning, and production operations. |
| **10** | [Interview Preparation](interview-preparation.md) | Revise throughout your study and practice before interviews. |

## How to use this sequence

1. Open Stage 01 and follow the numbered topics inside it.
2. Continue using the next-stage link at the bottom of each path.
3. Skip foundation topics you already know; repeated links are revision.
4. Data engineering is a parallel specialization and can start after Stage 03. Interview preparation can run alongside any stage.
5. Within Data Science, study deep learning and NLP before the LLM-focused stages. Time series and causal inference are specializations you can revisit as needed.
6. A Planned topic is a reserved outline, not an available lesson. Coverage labels describe the library; checkboxes track your personal progress.

Topic folders hold each resource once. Learning paths provide the study sequence without duplicating files.
