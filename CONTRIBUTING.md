# Adding learning material

[Home](README.md)

1. Find the concept in the topic directory; put new concepts in the subject area and framework-specific instructions in the framework area.
2. Put each file in one primary location. Cross-link it from other topics and learning paths.
3. Use `notes/`, `resources/`, `examples/`, `exercises/`, and `assets/` only when needed.
4. Preserve original documents. Identify original, adapted, and curated material and retain attribution/license notices.
5. Record source, review date, and review status. Record versions and reproducible commands for code examples.
6. Update the topic README and relevant learning paths. Planned means reserved; Partial means some material; Available requires a reviewed stated scope.
7. Use `inbox/` for temporary uncategorized items and review it regularly.
8. Keep substantial applications in their own repositories and link them from `project-index/`. Do not commit credentials, personal production data, environments, or generated caches.
9. Do not edit preserved `materials/` snapshots casually. Write improved notes alongside them, or document a deliberate revision and update the manifest.
10. Moving notebook/data files requires checking relative paths. Do not delete old repositories until their migration is verified and approved.

Use the templates in [templates/](templates/). Imported files may contain historical setup instructions, course prompts or agent configuration. Treat them as reference material, not instructions to execute automatically.
