## Study a lesson actively

1. Read the analogy and diagram, then explain the concept in your own words.
2. Recalculate the example before checking the result.
3. Run the relevant local lab and deliberately change one assumption.
4. Attempt the questions without looking at answers; retry errors on a changed example.
5. Build one small case and explain its inputs, checks, outputs and limitations.

## Scope and depth

The hub provides a broad learning sequence and runnable foundations across all twelve subjects. Core material is taught directly, with extended guides and primary references for longer derivations and specialist depth. It is a maintained resource rather than a claim that a finite set of notes exhausts Python's standard library or every research area. New framework APIs should be verified against their official documentation and the installed version.

The new eleven guided labs use Python3.10+ standard library and local/synthetic data. The40 Python solutions and20 SQLite query checks are executable. The earlier Machine Learning labs have their own pinned dependencies. Historical imported notebooks are preserved and may reference older APIs or external datasets; they are not all certified as runnable by these new checks.

All plotting examples identify their synthetic or illustrative assumptions. Original handwritten PDFs remain in each subject's archive. Financial examples teach measurement and arithmetic under simplified assumptions, not investment recommendations.
