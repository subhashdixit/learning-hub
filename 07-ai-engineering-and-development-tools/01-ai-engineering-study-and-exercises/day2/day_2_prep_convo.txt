  ---
  📚 ALL 5 PROMPTING TECHNIQUES - Real-Life Analogies

  1. Zero-Shot = Recipe from Memory

  Analogy: You ask a chef to make "spaghetti carbonara" without showing them a
  recipe.
  - Chef knows what carbonara is from experience
  - No examples needed
  - Works if it's a common dish

  When to use: Task is common/simple, no special format needed

  ---
  2. Few-Shot = Learning by Examples

  Analogy: You show a chef 3 plated dishes with specific garnishing style, THEN
  ask them to make the 4th dish in the same style.
  - Chef sees the pattern from examples
  - Learns the exact format/style you want
  - Better for unusual presentations

  When to use: Need specific format, unusual style, or domain-specific output

  ---
  3. Chain-of-Thought (CoT) = Show Your Work

  Analogy: You ask a math tutor to solve a problem but say "explain each step
  out loud."
  - Forces step-by-step thinking
  - Shows the reasoning process
  - Catches mistakes by thinking through it

  When to use: Complex reasoning, math, logic puzzles, multi-step problems

  ---
  4. Structured Output = Filling a Form

  Analogy: Like a tax form - specific fields must be filled exactly (name,
  address, income).
  - Fixed format (JSON/XML)
  - Validation possible
  - Guaranteed structure

  When to use: Need to parse output programmatically, database inserts, API
  calls

  ---
  5. Prompt Injection Prevention = Security Guard

  Analogy: Security guard checking bags at airport - stops dangerous items.
  - Validates user input
  - Blocks malicious instructions
  - Protects your system

  When to use: User-facing apps, when users can input text that goes to Claude

  Layer 3: EXTERNAL SERVICE (GitHub, Slack, DB)

  3 Message Types (MEMORIZE!):

  1. initialize - Handshake
    - Client: "Hi, I'm my-client v1.0"

  2. tools/list - Discovery
    - Client: "What tools do you have?"
    - Server: "I have create_issue, list_prs, merge_pr..."
  3. tools/call - Execution
    - Client: "Run create_issue with these params"
    - Server: "Done! Here's the result"

  Communication:

  - Uses JSON-RPC 2.0
  - Over stdio (pipes) or HTTP/SSE
