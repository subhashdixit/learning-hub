# 1. Python Output

```python
# Python is a case sensitive language
print('Hello World')
```

Recorded output:
```text
Hello World
```

```python
print('salman khan')
```

Recorded output:
```text
salman khan
```

```python
print(salman khan)
```

```python
print(7)
```

Recorded output:
```text
7
```

```python
print(7.7)
```

Recorded output:
```text
7.7
```

```python
print(True)
```

Recorded output:
```text
True
```

```python
print('Hello',1,4.5,True)
```

Recorded output:
```text
Hello 1 4.5 True
```

```python
print('Hello',1,4.5,True,sep='/')
```

Recorded output:
```text
Hello/1/4.5/True
```

```python
print('hello')
print('world')
```

Recorded output:
```text
hello
world
```

```python
print('hello',end='-')
print('world')
```

Recorded output:
```text
hello-world
```
