# 2. Data Types

```python
# Integer
print(8)
# 1*10^308
print(1e309)
```

Recorded output:
```text
8
inf
```

```python
# Decimal/Float
print(8.55)
print(1.7e309)
```

Recorded output:
```text
8.55
inf
```

```python
# Boolean
print(True)
print(False)
```

Recorded output:
```text
True
False
```

```python
# Text/String
print('Hello World')
```

Recorded output:
```text
Hello World
```

```python
# complex
print(5+6j)
```

Recorded output:
```text
(5+6j)
```

```python
# List-> C-> Array
print([1,2,3,4,5])
```

Recorded output:
```text
[1, 2, 3, 4, 5]
```

```python
# Tuple
print((1,2,3,4,5))
```

Recorded output:
```text
(1, 2, 3, 4, 5)
```

```python
# Sets
print({1,2,3,4,5})
```

Recorded output:
```text
{1, 2, 3, 4, 5}
```

```python
# Dictionary
print({'name':'Nitish','gender':'Male','weight':70})
```

Recorded output:
```text
{'name': 'Nitish', 'gender': 'Male', 'weight': 70}
```

```python
# type
type([1,2,3])
```

Recorded output:
```text
list
```
